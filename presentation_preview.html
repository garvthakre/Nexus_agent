Autonomous Action, Not Chat
Nexus works the ticket from open to closed
1. READ
Ingests ticket data
Extracts transaction ID, user claim, and order details.
2. PLAN
Compiles steps
Translates task into a strict multi-step browser plan.
3. REVIEW
Audits safety risks
LLM reviews plan; confirms steps before execution.
[Human in the loop: safety verdict + confirm step]
4. ACT
Operates screens
Navigates dashboards, fills forms, clicks buttons.
5. LOG
Records every action
Appends execution trace to immutable JSONL audit log.
TARGET WORKFLOW: FAILED-PAYMENT DISPUTE
A failed-payment dispute arrives. Nexus reads context, plans steps, reviews safety, checks status in the portal, picks refund or escalate, updates the ticket, and logs every step.
Target workflow for customer operations. Humans only handle unresolved edge cases.

INTELLIGENCE LAYER
Planner (planner.ts)

Safety Reviewer
Independent LLM safety audit: returns SAFE, REVIEW_REQUIRED, or UNSAFE with risk flags.
Provider Failover [Built]
Automated fallback routing across Groq Llama 3.3 70B, OpenAI GPT-4o, and Anthropic Claude.
